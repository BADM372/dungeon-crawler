Dice inside the computer

Games need dice. Where does the spider stand? Which sword does the chest hold? Is this cube a meadow or a lake?

But a computer is an exact machine. It does the same thing every time. It cannot really roll a die!

So it uses a trick. It takes a number and puts it through a scrambling formula. Out comes a new number that looks random. Put that one through the formula again, and you get the next one. And so on, forever.

The very first number is called the seed. Everything grows from the seed, like a plant.

The big secret

The same seed always gives exactly the same numbers, in the same order.

So the same seed gives the same world: the same hills, the same rivers, the same monsters in the same places.

Try it in the game: ?seed=123 and then ?seed=124. Visit them twice. The town is always there, but the cubes behind it change with the seed.

Try it: same seed, same dice

Seed A and seed B start the same. Roll a few times: the seeded rows are the same every time. The bottom row uses the browser's own Math.random(), which picks a new secret seed itself, so it changes.

This uses the game's real dice, the function mulberry32 from src/core/util.js.

Why "not really random" is great

Hunting bugs

If a bridge is broken in world 123, a developer (or an AI helper) can open world 123 and see the exact same broken bridge. Fixing a bug you cannot see again is almost impossible.

Tests

The game's tests build hundreds of worlds with fixed seeds and check them. Because the seeds are fixed, a test that passes today passes tomorrow, unless the code changed.

No cheating

What a monster drops is decided by the world seed and the monster's name. If you die and the monster comes back, it drops the same thing again. Dying on purpose does not give you better loot!

Every cube gets its own dice

If the whole world used one row of dice, building cube A first or cube B first would change both of them. Messy!

So every cube makes its own seed: it mixes the world seed with its own name, like "2,-1,0" (that is: 2 east, depth 1, 0 south).

The mixer is called a hash: a formula that turns anything into a number that looks random. A tiny change in the name gives a totally different number.

The walls between cubes, the monsters, the loot and the decorations get their own streams too.

A bag of marbles

Not everything should be equally likely. A rare sword should be rare! So the game uses weights: imagine a bag with 24 grey marbles (Junk), 40 white (Common), 22 green (Uncommon) and 8 blue (Rare). Grab one without looking.

The game uses this for almost every choice: which kind of cube, which archetype, which monster, which sword, which name.

The real dice: mulberry32

export function mulberry32(a) {
  return function () {
    a |= 0; a = a + 0x6D2B79F5 | 0;
    let t = Math.imul(a ^ a >>> 15, 1 | a);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}

Don't worry about every symbol. Here is the idea:

  • mulberry32(seed) gives you a function. Each time you call it, you get the next number between 0 and 1.
  • Inside, a remembers where we are. Each call adds a big odd number to it.
  • Math.imul, ^ and >>> multiply, flip and shift the bits: they shuffle the number like a deck of cards.
  • Dividing by 4294967296 (that is 232) squeezes the result between 0 and 1.

To roll a die: Math.floor(R() * 6) + 1.

The real marble bag

// how a cube picks its archetype (chasm, spire, mesa, ...)
function archetype(theme, kind, R) {
  const w = Object.entries(theme.arche)
    .map(([a, v]) => [a, v * (LEAN[kind]?.[a] ?? 1)]);
  let r = R() * w.reduce((s, [, v]) => s + v, 0);
  for (const [a, v] of w) if ((r -= v) < 0) return a;
  return 'plain';
}

Read it like the marble demo:

  1. w is the list of choices and their weights. The theme sets them, and the kind of cube leans them: a lake cube makes islands three times more likely.
  2. R() * sum throws the needle onto the line.
  3. The loop walks along: subtract each weight. When we go below zero, that's our pick.
  4. The last line is a safety net that should never be needed.
